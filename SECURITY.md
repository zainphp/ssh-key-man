# Security policy

Report security issues privately through [GitHub's vulnerability reporting form](https://github.com/zainphp/ssh-key-man/security/advisories/new).

Include the affected version, operating system, steps to reproduce the issue, and its impact. Remove private keys, passphrases, access tokens, and other secrets from your report.

Keep vulnerability details out of public issues and pull requests while maintainers review the report and coordinate a fix.
